I added documentation to the Universal LPC Spritesheet Character Generator, an open-source tool used to generate game character sprite sheets. I added a section to its README that outlined every custom animation that used a non-default frame size, information that previously only existed buried in the project's source code.

It was a small, well-scoped task, but I still caught a real mistake in my own pull request before submitting it — a miscounted test result — using a review checklist I'd built myself. I fixed it, then opened the fix.

The maintainer merged it on November 11, 2026, closing out an issue a user had reported after stumbling onto the problem by accident.

Even simple open-source contributions reward double-checking your own work before anyone else sees it. I'm looking forward to contributing again.
